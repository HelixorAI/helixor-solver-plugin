# Using Helixor platform guidance

Start here when helping a user choose or use the Helixor platform. This
foundation organizes product guidance. This package carries the two solver
skills as Preview guidance.
Always check the applicable version and deployment before execution.

1. Read [platform.md](platform.md) for the intended product map and
   [terminology.md](terminology.md) for vocabulary and distinctions.
2. Use [workflows.md](workflows.md) to identify the task, runtime placement,
   service operation, and available access interface.
3. Select the relevant service from [catalog.json](catalog.json), then read
   its `SKILL.md` and the workflow reference it names.
4. Apply [sources.md](sources.md) before making capability or operational
   claims. Use a verified source or state the gap clearly.

Reading and explaining documented behavior does not require MCP. Execution
requires an available, verified interface and appropriate user authorization.
Installing a skill does not connect a service, supply credentials, or grant
permission to change an account or deployment.

Both solver skills use [shared solver guidance](solver/README.md), including
all optimization terminology, pattern recipes, modeling and result evidence.
Their own guides retain runtime invocation and service setup respectively.

Keep the answer focused: chosen path, evidence, prerequisites, next action,
and any gap that blocks the user's task. Ask only about facts that would change
the path and cannot be established from supplied sources.
